[프로젝트 현황 요약 — Pygame 2D 로그라이크 미로 게임]

목표: Pygame으로 2D 로그라이크 미로 게임 제작. 현재는 프로젝트 기본 구조 + 최소 동작 가능한 골격(playable skeleton)만 완성된 단계.

위치: C:\work\MAZE (Windows, Python 3.13, venv 사용 중)

폴더 구조
MAZE/
├── main.py                # 진입점: Game().run() 호출
├── requirements.txt       # pygame>=2.5.0
├── .gitignore             # venv/, __pycache__
├── assets/
│   ├── images/            # 비어 있음 (스프라이트 없음, 전부 색상 도형으로 렌더링 중)
│   ├── sounds/            # 비어 있음
│   └── fonts/             # 비어 있음 (기본 시스템 폰트 사용 중)
└── src/
    ├── settings.py         # 전역 상수 (화면 960x640, 타일 32px, 미로 21x15, 색상, FPS 60, 이동 쿨다운 120ms)
    ├── maze_generator.py   # 재귀 백트래킹(DFS) 방식 미로 생성기 (MazeGenerator 클래스)

    └── game.py             # Game 클래스: 초기화/이벤트/업데이트/렌더링 루프

현재 구현된 기능
- 재귀 백트래킹 알고리즘으로 매 실행 시 랜덤 미로 생성 (MazeGenerator)
- 플레이어는 WASD/방향키로 타일 단위 이동, 벽 통과 불가, 이동 쿨다운(120ms)으로 속도 제한
- 미로의 가장 우측-하단 통로 칸을 자동으로 "출구"로 지정 (노란색 타일)
- 플레이어가 출구 칸에 도달하면 "탈출 성공" 상태(cleared)로 전환, 화면 하단에 안내 문구 표시
- R키로 미로 재생성, ESC로 종료
- 미로는 화면 중앙에 자동 정렬되어 그려짐 (오프셋 계산)
- pygame 설치 및 headless(SDL_VIDEODRIVER=dummy) 스모크 테스트로 정상 동작 확인 완료

아직 없는 것 / 미구현 (전형적인 로그라이크 요소들)

- 테스트 코드 (unit test 없음, 수동 스모크 테스트만 진행)

결정이 필요한 질문 (다음 세션에서 방향 잡을 때 참고)
1. 로그라이크의 핵심 정체성을 무엇으로 잡을지 — 턴제 vs 실시간(현재는 실시간 쿨다운 이동), permadeath 여부, 절차적 던전 vs 고정 맵+절차적 미로
2. 전투 시스템 유무와 방식 (근접/원거리, 턴제 전투 vs 실시간 충돌)
3. 아트 스타일 — 색상 도형 유지할지, 픽셀아트 타일셋을 붙일지 (assets/images 활용 여부)
4. 맵 스케일 — 미로를 화면보다 크게 만들어 카메라 스크롤을 도입할지
5. 진행 구조 — 단일 미로 클리어 후 종료 vs 여러 층을 내려가는 던전 크롤러 형태
