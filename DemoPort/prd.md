# 개발자 프로필 웹사이트 PRD

## 1. 개요

### 1.1 목적
개발자 안현욱의 개인 프로필 및 포트폴리오를 소개하는 웹사이트를 제작한다. 방문자(채용 담당자, 협업 대상자, 동료 개발자 등)가 짧은 시간 안에 개발자의 정체성, 전문 분야, 대표 프로젝트, 연락 방법을 파악할 수 있도록 하는 것을 목표로 한다.

### 1.2 대상 사용자
- 채용 담당자 / 리크루터

## 2. 목표 및 성공 지표

### 2.1 목표
- 개발자의 전문성과 개성을 명확하게 전달
- 대표 프로젝트를 시각적으로 보기 좋게 소개
- 연락(이메일)로 이어지는 명확한 경로 제공
- 모바일/데스크톱 모두에서 자연스러운 사용자 경험 제공

### 2.2 성공 지표 (예시)
- 방문자가 3초 이내에 "누구인지, 무엇을 하는지" 파악 가능
- 모바일 환경에서 레이아웃 깨짐 없이 정상 노출
- 페이지 로딩 속도 2초 이내
